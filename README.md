# fanorona（马达加斯加棋）

极简 Fanorona 引擎：9×5 棋盘上的迎击/撤击吃子对弈。纯 Python 标准库，无第三方依赖。

## 玩法

- 9 列 × 5 行共 45 个交叉点；斜线只存在于"行+列为偶数"的强点之间。
- 双方各 22 子，开局摆满除中心点外的所有交叉点，**白方先走**。
- 每回合沿线走一格到空点。吃子二选一：
  - **迎击**：走向敌子，吃掉落点前方同一直线上的全部连续敌子；
  - **撤击**：远离相邻敌子，吃掉起点后方同一直线上的全部连续敌子。
- **有吃必吃**；多条吃法并存时，必须选"全程（含连吃）吃子总数最多"的一条。
- 连吃：同一子可继续吃子，但一回合内不能落到已走过的点，也不能沿与上一次吃子相同的方向继续吃。
- 吃光对方棋子者胜；轮到走棋但无合法走法者负。
- 三次重复局面判和；400 半回合上限判和（防止无限对局）。

## 用法

```bash
python3 -m fanorona                 # 人机对战（你执白 ○，AI 执黑 ●）
python3 -m fanorona --auto --games 10 --seed 42   # AI 对 AI 自动演示
python3 -m fanorona --auto --games 5 --verbose    # 打印每步
```

走法输入示例：`e2 e3`；同一步有迎击/撤击两种吃法时加后缀 `a`/`w`，如 `e2 e3 a`。
连吃时输入落点继续，或输入 `stop` 结束本回合；`q` 退出。

## 真实验证记录

- `py_compile fanorona.py __main__.py`：通过。
- 18 项单元测试（`/tmp/test_fanorona.py`，不入库）：**18/18 通过**。
  覆盖：开局 22+22 子与中心空点；迎击吃 2 子；撤击吃 2 子；
  必吃最长（吃 1 vs 吃 2 只保留吃 2）；有吃必吃（无 paika 混入）；
  弱点无斜走、强点有斜走；被困无走法判负；吃光判胜；连吃不走回头路。
- `--auto --games 10 --seed 42`：10 局全部正常结束，**白胜 5 / 黑胜 5 / 和棋 0**，
  17–96 半回合/局，全部以吃光对方收官，无崩溃。
- `--verbose` 抽查：迎击/撤击交替的连吃链正确（如 `d3→d2 迎击吃 1` 接 `d2→e3 撤击吃 1`）。
- 非终端运行交互模式：中文提示并 exit 2。

## 诚实局限

- **AI 很弱**：只是"必吃最长 + 平局随机种子"的贪心策略，无深层搜索、无开局库；
  熟悉 Fanorona 定式的人类通常能赢。
- 连吃"不许同向"与"不走回头路"是本实现的规则选择；真实 Fanorona 在不同地区/文献中
  对连吃限制的表述略有差异，README 已如实说明采用的版本。
- 文本棋盘（斜线未绘制，靠走法列表保证合法性），无图形界面、无存档、无悔棋。
- Python 3.10+，纯标准库。
